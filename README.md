Lotify is a JavaFX-based parking lot management system designed to streamline vehicle monitoring and notification handling with persistent database integration. Built with a modular architecture, it provides a clean, user-friendly interface for managing parking operations efficiently.

🚗 Features

Vehicle registration, editing, and removal

Parking lot management with real-time status updates

Notification manager for alerts and reminders

Persistent storage with MySQL integration

Modular JavaFX design for scalability and maintainability

🛠 Tech Stack

Language: Java 24

Framework: JavaFX 24

Database: MySQL (via JDBC)

Build Tool: Maven
